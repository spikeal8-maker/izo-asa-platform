Официальный queue contract: submit возвращает `request_id` и operation URLs; status/result

не гарантирует остановку. Модель принимает custom `image_size` width/height, один PNG output и
включённый safety checker. Цена провайдера не является product Credits и задаётся оператором
через `IZO_FAL_PRICE_MICROUSD_PER_MP` вместе с отдельным `IZO_FAL_MAX_COST_MICROUSD`.

### Privacy boundary fal

Submit явно отправляет `X-Fal-Store-IO: 0`, поэтому JSON input/output не должен попадать в стандартное
30-дневное server-side хранение fal. Для generated media задаётся отдельный lifecycle preference: по умолчанию
в этом adapter — 3600 секунд. Это не делает fal media private: provider URL остаётся публичным в пределах TTL,
поэтому worker забирает файл сразу, принимает только HTTPS `fal.media`/`*.fal.media`, запрещает redirect,
ограничивает размер и переписывает изображение через `media.codec` перед помещением в приватное S3.
Передача prompt внешнему provider всё равно является внешней обработкой данных; API-001 не является
юридическим/privacy approval для production или данных детей.

## Исправленные архитектурные разрывы

1. Public image contract больше не зашит в единственный `test.image.v1`; catalog имеет два finite capability.
2. `test.image.v1` сохранён как deterministic бесплатный regression-provider.
3. Для внешнего provider до network submit создаётся durable `generation_provider_calls`.
4. Сохраняются connection/credential reference, provider request ID, проверенные queue URLs и cost metadata;
   значение API key не сохраняется.
5. Потерянный submit response переводит Job в `provider_submission_unknown`; automatic paid retry запрещён.
6. Lease recovery с известным request ID продолжает status/result существующей provider operation.
7. Cancel после provider intent не делает мгновенный refund. Queue cancellation освобождает reserve только
   после подтверждения; in-progress cancellation остаётся advisory и может закончиться success/settlement.
8. Provider media URL проверяется как HTTPS `fal.media`/`*.fal.media`, redirect не принимается, download bounded;
   затем файл проходит существующий isolated `media.codec.decode()` и только после этого S3/settlement.
9. API container не получает provider key и не имеет provider-egress network. Отдельный `fal-worker` получает
   key и egress; default CI его не запускает.
10. UI выбирает capability из server plan и показывает test/real AI явно, оставаясь на общем jobs/media transport.

## Cost / budget

Product reserve для этой первой capability остаётся существующей целочисленной единицей Credits и не
выдаётся за себестоимость. Provider estimate хранится отдельно в microUSD. Admission закрыт, если operator
не задал ненулевую цену/MP и max-cost cap или если estimate превышает cap. Reported provider cost может
оставаться NULL, если provider API его не сообщает; он не подменяется нулём.

## Live boundary

Unit/HTTP/browser tests не используют сеть и настоящий fal key. Реальный fal call допустим только отдельным
действием владельца после успешного CI, с тестовым аккаунтом, отдельным key и согласованным max-cost.
До этого статус пакета: code/contract implemented, live-provider acceptance = NO.
